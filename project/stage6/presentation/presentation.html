Цель и задачи

Цель: разместить двуязычную версию персонального сайта на GitHub Pages.

Задачи:

  • сделать поддержку английского и русского языков;
  • разместить элементы сайта на обоих языках;
  • разместить контент на обоих языках;
  • сделать пост по прошедшей неделе;
  • добавить пост на тему по выбору на двух языках.

Теоретическая основа

Сайт разработан на базе генератора статических сайтов Hugo и шаблона HugoBlox.

Hugo поддерживает мультиязычность за счёт:

  • настройки языков в конфигурационных файлах;
  • разделения контента по каталогам;
  • связи переводов через translationKey;
  • использования переключателя языков на сайте.

Мультиязычность в Hugo

Для создания двуязычного сайта обычно:

  • задают языки в config/_default/languages.yaml;
  • определяют язык по умолчанию;
  • включают подкаталоги для языковых версий;
  • размещают материалы в content/ru/ и content/en/.

Это позволяет поддерживать отдельные русскую и английскую версии страниц, проектов и публикаций.

Настройка русского и английского языков

Это позволило организовать адреса сайта для двух языков (Рисунок 4).

Переключатель языков

Также был проверен файл params.yaml, где был включён переключатель языка в верхней и нижней части сайта.

Пост по прошедшей неделе

  • дата публикации;
  • краткое описание;
  • автор;
  • основной текст;
  • параметр draft: false.
